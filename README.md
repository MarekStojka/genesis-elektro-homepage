# Genesis Elektro — návrh homepage

První návrh nové hlavní stránky: tmavý industriální styl, červené akcenty a přepracovaný obsah.

## Spuštění

Otevřete `index.html` v prohlížeči. Není potřeba instalace ani sestavení.

## Obsah

- Responzivní homepage a mobilní navigace.
- Rozbalovací přehled služeb.
- Kontakty a příprava poptávky přes e-mailovou aplikaci (bez serverového odesílání).
- Ilustrační vizuál vytvořený pomocí AI; nejde o fotografii realizace firmy.
- Písma Barlow a Barlow Condensed se načítají z Google Fonts.

Návrh slouží k připomínkování designu a obsahu. Logo je prozatímní typografické zpracování.
